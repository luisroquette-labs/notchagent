# NotchAgent 3.7.1

Shipped on 2026-11-20 as a signed, notarized GitHub Release. The Direct DMG is
https://github.com/luisroquette-labs/notchagent/releases/download/v3.7.1/NotchAgent-3.7.1.dmg
and the Homebrew cask is 3.7.1. The commands below are the record of that cut.

`VERSION`, the Direct bundle, the appcast, and the changelog heading are 3.7.1
dated 2026-11-20. Homebrew cask `luisroquette-labs/tap/notchagent` is 3.7.1.
On some Homebrew versions, run `brew trust --cask luisroquette-labs/tap/notchagent`
before `brew install --cask --no-quarantine luisroquette-labs/tap/notchagent`.

## Highlights since 3.5.5

Direct users jumping from 3.5.5 get everything below.

### Codex

- Official quota cache no longer goes stale in silence. A cap on cache age means a stuck read cannot freeze the gauge.
- Free rate-limit reset credits show in the notch, including how many you have and when the soonest one expires.
- The button that uses a reset opens OpenAI's own usage screen. NotchAgent does not spend the credit.
- The Codex app-server reader no longer pegs a CPU core when the stream ends.

### Claude plans

- When the quota probe reports a weekly window and no 5-hour window — verified Ultra accounts whose 5-hour limit was removed — the card says there is no 5-hour session limit and the weekly window becomes the headline, in Portuguese, English, and Spanish.
- The burn panel follows that signal. A limit that no longer exists is not drawn from the local transcript.

### Mac App Store edition

- Sandboxed build, separate from the Developer ID / Sparkle channel.
- First launch walks through the Claude Code, Claude Desktop, and Codex folders in Portuguese, English, and Spanish, and checks that the folder actually contains readable sessions.
- Setup distinguishes a granted folder from usable local sessions, explains why cloud tasks do not appear, and links to the official Codex quota.
- An authorized empty Codex folder is no longer described as a missing install.

### English interface

- Notch chrome that was still Portuguese in the English panel is English: paid spend, API account labels, plan notes, and the menu bar, dashboard, and spend window when Language is English.
- A new install follows the Mac language. Saved settings keep the language already chosen. Older settings files that have no language field stay Portuguese.

## What this release does not include

- No new account, no telemetry, and no paid model request beyond the optional Claude probe that already exists and can be turned off.
- The weather city in the notch is the Mac's location from a one-time geo-IP lookup (city plus country code, for example a city in Brazil). It is not a bundled place name. Set **Settings → City override** before taking English screenshots.

## Publish on your Mac

Run this from a clean checkout of `master` after this pull request is merged.
Replace the three exports with the certificate, notary profile, and Sparkle
values you used for 3.5.5. Do not paste those secrets into git.

```bash
cd /path/to/notchagent
git checkout master
git pull origin master

printf '3.7.1\n' > VERSION
plutil -replace CFBundleShortVersionString -string 3.7.1 Resources/Info.plist

python3 - << 'PY'
from pathlib import Path
path = Path("project.yml")
text = path.read_text()
start = text.index("  NotchAgent:\n")
end = text.index("  NotchAgentAppStore:\n")
block = text[start:end]
block = block.replace('CFBundleShortVersionString: "3.5.5"', 'CFBundleShortVersionString: "3.7.1"', 1)
block = block.replace('MARKETING_VERSION: "3.5.5"', 'MARKETING_VERSION: "3.7.1"', 1)
path.write_text(text[:start] + block + text[end:])
PY

python3 - << 'PY'
from pathlib import Path
path = Path("README.md")
path.write_text(path.read_text().replace("**Current version: 3.5.5**", "**Current version: 3.7.1**", 1))
PY

# check-version.sh requires a heading that starts with "## 3.7.1 — "
# The unreleased heading already matches. Set the ship date when you publish:
perl -i -pe 's/^## 3\.7\.1 — unreleased Direct/## 3.7.1 — 2026-12-01/' CHANGELOG.md

./Scripts/check-version.sh
./Scripts/audit-public-release.sh
NOTCHAGENT_DISABLE_PAID_PROBES=1 swift test

export NOTCHAGENT_SIGN_IDENTITY="Developer ID Application: YOUR NAME (TEAMID)"
export NOTCHAGENT_NOTARY_PROFILE="YOUR_NOTARYTOOL_KEYCHAIN_PROFILE"
export NOTCHAGENT_UPDATE_FEED_URL="https://YOUR_APPCAST_HOST/appcast.xml"
export NOTCHAGENT_UPDATE_PUBLIC_ED_KEY="YOUR_SPARKLE_ED25519_PUBLIC_KEY"
export NOTCHAGENT_UPDATE_DOWNLOAD_URL_PREFIX="https://github.com/luisroquette-labs/notchagent/releases/download/v3.7.1/"

./Scripts/make-app.sh
./Scripts/notarize-app.sh dist/NotchAgent.app
./Scripts/make-notarized-dmg.sh dist/NotchAgent.app
./Scripts/generate-update-appcast.sh dist/NotchAgent-3.7.1.zip dist/updates

spctl --assess --type execute --verbose=2 dist/NotchAgent.app
spctl --assess --type open --context context:primary-signature --verbose=2 dist/NotchAgent-3.7.1.dmg
shasum -a 256 dist/NotchAgent-3.7.1.zip dist/NotchAgent-3.7.1.dmg

# Commit the version bump and the generated appcast only after the commands above pass.
git add VERSION Resources/Info.plist project.yml README.md CHANGELOG.md appcast.xml
git commit -m "chore(release): direct channel 3.7.1"
git push origin master

gh release create v3.7.1 \
  dist/NotchAgent-3.7.1.zip \
  dist/NotchAgent-3.7.1.dmg \
  --repo luisroquette-labs/notchagent \
  --title "NotchAgent 3.7.1" \
  --notes-file docs/release-notes/3.7.1.md
```

`notarize-app.sh` writes `dist/NotchAgent-3.7.1.zip` and refuses to overwrite an existing zip.
`make-notarized-dmg.sh` writes `dist/NotchAgent-3.7.1.dmg`.
`generate-update-appcast.sh` only writes a local appcast. It does not upload.

Sparkle's build number for 3.5.5 in `appcast.xml` is 12. `BUILD_NUMBER` is already 25, which is what `make-app.sh` stamps, so a 3.7.1 build sorts after 3.5.5. Leave `BUILD_NUMBER` alone unless you intentionally ship another build.

## Homebrew cask

Do this only after `v3.7.1` exists and `NotchAgent-3.7.1.dmg` is attached to it.
The cask in `luisroquette-labs/homebrew-tap` is still `version "3.5.5"` with sha256
`8d1249f0461f90b08431534fdc07d777be3ec8551be08b1529a0cd1a17e83d10`.

```bash
cd /tmp
rm -f /tmp/NotchAgent-3.7.1.dmg
rm -rf /tmp/homebrew-tap
gh release download v3.7.1 --repo luisroquette-labs/notchagent --pattern 'NotchAgent-3.7.1.dmg' --dir /tmp
DMG_SHA=$(shasum -a 256 /tmp/NotchAgent-3.7.1.dmg | awk '{print $1}')
echo "DMG sha256 $DMG_SHA"

git clone https://github.com/luisroquette-labs/homebrew-tap.git
cd homebrew-tap
python3 - "$DMG_SHA" << 'PY'
import pathlib, sys
sha = sys.argv[1]
path = pathlib.Path("Casks/notchagent.rb")
text = path.read_text()
old = 'sha256 "8d1249f0461f90b08431534fdc07d777be3ec8551be08b1529a0cd1a17e83d10"'
if 'version "3.5.5"' not in text or old not in text:
    raise SystemExit("Casks/notchagent.rb is not the 3.5.5 cask this script expects. Edit version and sha256 by hand.")
path.write_text(text.replace('version "3.5.5"', 'version "3.7.1"', 1).replace(old, f'sha256 "{sha}"', 1))
PY
git diff
git add Casks/notchagent.rb
git commit -m "notchagent 3.7.1"
git push origin master

brew untap luisroquette-labs/tap || true
brew tap luisroquette-labs/tap
brew install --cask --no-quarantine luisroquette-labs/tap/notchagent
brew info --cask luisroquette-labs/tap/notchagent
```

## English Product Hunt page

`notchagent.app` is [luisroquette-labs/notchagent-site](https://github.com/luisroquette-labs/notchagent-site), deployed on Vercel. This app repo's GitHub Pages only redirects `/` to that site. The English page in this repo is `docs/producthunt/` and is also what GitHub Pages will serve at `/producthunt/` after this lands.

```bash
git clone https://github.com/luisroquette-labs/notchagent-site.git
cd notchagent-site
mkdir -p public/producthunt
cp /path/to/notchagent/docs/producthunt/index.html public/producthunt/index.html
cp /path/to/notchagent/docs/producthunt/styles.css public/producthunt/styles.css
git add public/producthunt
git commit -m "Add English Product Hunt landing without a download form"
git push origin main
```

Images stay as `../img/…`, which is `public/img` on the site. Confirm
`https://notchagent.app/producthunt` loads in English and the download links
go straight to the App Store, GitHub Releases, and the Homebrew command.
